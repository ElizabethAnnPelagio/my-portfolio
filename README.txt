GITHUB PORTFOLIO - VS CODE STARTER FOLDER

FILES
- index.html : content ng portfolio website
- style.css  : design, colors, layout, responsive/mobile styles
- script.js  : mobile navigation at current year
- assets/    : dito mo puwedeng ilagay ang profile photo o ibang images

PAANO BUKSAN SA VISUAL STUDIO CODE
1. I-extract muna ang ZIP file.
2. Buksan ang Visual Studio Code.
3. Piliin ang File > Open Folder.
4. Piliin ang folder na "github_portfolio_vscode" na na-extract mo.
5. Buksan ang index.html.
6. Para makita ang website, puwede mong i-install ang "Live Server" extension.
7. Pagkatapos, i-right-click ang index.html at piliin ang "Open with Live Server".
   Kung wala kang Live Server, puwede ring i-double-click ang index.html sa File Explorer.

PAANO I-PUBLISH SA GITHUB PAGES
1. Gumawa o mag-sign in sa GitHub account.
2. Gumawa ng bagong repository, halimbawa: my-portfolio.
3. I-upload ang index.html, style.css, script.js, README.txt, at assets folder
   sa root/main level ng repository (huwag ang ZIP file lang).
4. Sa repository, pumunta sa Settings > Pages.
5. Sa Build and deployment, piliin ang Deploy from a branch.
6. Piliin ang branch na main at folder na /(root), pagkatapos Save.
7. Hintaying matapos ang deployment. Lalabas ang website link sa Pages section.

MGA DAPAT I-EDIT BAGO I-PUBLISH
- Sa index.html, palitan ang sample email at social links.
- I-update ang About Me paragraph.
- I-update ang MPCA entry gamit ang buong pangalan at school year.
- Palitan ang Certificate Title at project placeholders ng totoong impormasyon.
- Hindi kailangan maglagay ng profile photo ngayon. Placeholder muna ang nasa website.

NOTE
Static HTML/CSS/JavaScript ito; hindi kailangan ng framework o build command.
