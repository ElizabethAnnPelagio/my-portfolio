ELIZABETH PORTFOLIO - VS CODE / GITHUB PAGES

FILES
- index.html: website content
- style.css: colors, layout, responsive styling
- script.js: mobile navigation and footer year
- images/profile.jpg: add your profile photo here (use this exact filename)
- certificates/certificate.jpg: optional certificate image (use this exact filename)

OPEN IN VS CODE
1. Extract the ZIP file.
2. Open Visual Studio Code.
3. Choose File > Open Folder.
4. Select the elizabeth_portfolio folder.
5. Open index.html and use Live Server if you have that extension installed, or open index.html in your browser.

ADD YOUR PROFILE PHOTO
Copy your photo into the images folder and rename it profile.jpg. Keep the filename and folder spelling exactly as shown.

ADD A CERTIFICATE
Copy a certificate image into the certificates folder and name it certificate.jpg. If you do not have one yet, the site displays a placeholder.

UPLOAD TO GITHUB
1. Open your repository: https://github.com/ElizabethAnnPelagio/my-portfolio
2. Upload index.html, style.css, script.js, README.txt, and the images/certificates folders (with your image files if available).
3. Commit your changes to the main branch.
4. In repository Settings > Pages, select Deploy from a branch, choose main and /(root), then Save.

PRIVACY
This version does not display birthday, age, or birthplace. Review all content and images before publishing publicly.
